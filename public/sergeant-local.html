Turn it on from the website

  1. Open the paper desk. The switch starts on Off. Off is Corporal.
  2. On your computer, run the command below and leave the window open. Point --project at a folder that exists.
  3. Click On. The badge should say “Sergeant on · this computer”.
  4. Click Off, or press Ctrl+C, to turn it off. The switch is stored in that browser only.
cd tools/sergeant-local
python sergeant_local.py --serve --project C:\Users\YOU\BTD-commando

It listens only on 127.0.0.1:8765. Review the source before you run it. Never paste broker credentials into the prompt.
